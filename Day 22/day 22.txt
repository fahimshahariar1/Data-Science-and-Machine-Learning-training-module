Topics Covered:

Normal Ploting:

Bar Plot:
A bar plot is a graphical representation of categorical data, where categories are represented by rectangular bars. The length or height of each bar is proportional to the value it represents.

Categories: The different groups or items being compared.
Bars: Rectangular shapes representing the categories.
Length or height: The magnitude of the data for each category.
Axes: The horizontal axis (x-axis) represents the categories, and the vertical axis (y-axis) represents the values.

Types of Bar Plots
Vertical bar plots: Bars are oriented vertically.
Horizontal bar plots: Bars are oriented horizontally.
Stacked bar plots: Multiple categories are stacked on top of each other for comparison within categories.
Grouped bar plots: Multiple categories are grouped together for comparison across categories.

Histogram:
A histogram is a graphical representation of the distribution of numerical data. It divides the data into intervals or bins and counts the number of data points that fall into each bin. The height of each bar represents the frequency of data points within that bin.

Key Components of a Histogram:

Bins: Intervals or ranges of data values.
Frequency: The number of data points within each bin.
X-axis: Represents the bins or intervals.
Y-axis: Represents the frequency or count of data points.

When to Use a Histogram:

To understand the distribution of a dataset.
To identify patterns, such as normality, skewness, or outliers.

Scatter plot:
A scatter plot is a graphical representation used to visualize the relationship between two numerical variables. Each data point is plotted as a point on a two-dimensional graph, with one variable represented on the x-axis and the other on the y-axis.

Key Components:

Data points: Represent individual observations.
X-axis: Represents one variable.
Y-axis: Represents the other variable.
When to Use a Scatter Plot:

To identify correlations between two variables.
To explore potential relationships between variables.
To detect outliers or unusual patterns in data.
To compare distributions of different datasets.

Pie chart:

A pie chart is a circular statistical graphic which is divided into slices to illustrate numerical proportions. Each slice of the pie represents a category, and the size of the slice is proportional to the quantity it represents.   

Key components of a pie chart:

Circle: Represents the whole.
Slices: Represent the parts of the whole.
Labels: Indicate the category represented by each slice.
Percentages: Often displayed within or near each slice to show the proportion.
When to Use a Pie Chart
To show how a whole is divided into different categories.
To compare the relative sizes of different categories.
When the number of categories is relatively small (typically 5 or fewer).
Limitations of Pie Charts
Difficult to compare specific slices, especially when there are many categories.
Can be misleading if the slices are too similar in size.


Box Plot:
A box plot, also known as a box-and-whisker plot, is a graphical representation of the distribution of a dataset. It provides a visual summary of five key statistical measures:   

Minimum: The smallest value in the dataset.
First quartile (Q1): The value below which 25% of the data lies.
Median (Q2): The middle value of the dataset.
Third quartile (Q3): The value below which 75% of the data lies.
Maximum: The largest value in the dataset.
Components of a Box Plot
Box: Represents the interquartile range (IQR), which contains the middle 50% of the data.
Median line: A line within the box indicating the median value.
Whiskers: Lines extending from the box to the minimum and maximum values (or sometimes to specific percentiles).
Outliers: Individual data points that lie significantly outside the range of the other data.
When to Use a Box Plot
To visualize the distribution of data.
To compare distributions of different datasets.
To identify outliers.
To assess data spread and skewness.

Heat Map:
A heatmap is a graphical representation of data where values are represented by colors. It's particularly useful for visualizing data across two variables, often represented on a grid. Warmer colors typically indicate higher values, while cooler colors represent lower values.

Key Components
Grid: The underlying structure of the heatmap, with rows and columns representing different categories or values.
Color: Represents the magnitude of the data at each grid point.
Color scale: Defines the mapping between data values and colors.
When to Use Heatmaps
Identifying patterns and trends in data.
Comparing multiple variables simultaneously.
Visualizing correlations between variables.
Understanding the distribution of data across categories.
